# Tietoturva

## Haavoittuvuuden ilmoittaminen

Jos löydät sivustosta tai tästä reposta tietoturvaongelman, ilmoita siitä yksityisesti:

- sähköpostilla osoitteeseen oskari@summanen.org tai
- GitHubissa: **Security → Report a vulnerability**.

Älä avaa ongelmasta julkista issueta ennen kuin se on korjattu.

Sivusto on yhden ihmisen ylläpitämä vapaa-ajan projekti, joten vasteaikaa en voi luvata. Pyrin kuitenkin vastaamaan ja korjaamaan vakavat ongelmat mahdollisimman pian.

## Mitä ilmoitus voi koskea

- sivuston koodi (HTML, CSS, JavaScript) ja sen kautta tehtävät hyökkäykset, esimerkiksi haitallisen koodin ajaminen kävijän selaimessa
- sivulla käytetyt kirjastot (three.js, GSAP)
- evästeiden ja analytiikan toiminta suostumukseen nähden

Tietoturvaongelmia eivät ole esimerkiksi tekstien virheet, ulkoasu tai GitHub Pagesin ja muiden palveluntarjoajien (Google Analytics, Microsoft Clarity) omat ongelmat. Ne kannattaa ilmoittaa suoraan palvelun tarjoajalle.

## Tuetut versiot

Vain uusin julkaistu versio (osoitteessa https://summanen.org) on tuettu. Versiohistoria on tiedostossa [CHANGELOG.md](CHANGELOG.md).

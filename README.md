# summanen.org – nettisivut

Oskari Summasen henkilö- ja yrityssivu (summanen.org).

- `index.html` – koko sivu yhtenä tiedostona (tyylit, skriptit ja kuvat upotettuina).
- 3D-tausta (three.js) ja vierityksen animaatiot (GSAP) ladataan cdnjs.cloudflare.com-palvelusta.

Sivun voi avata suoraan selaimessa tai julkaista esimerkiksi GitHub Pagesilla.
